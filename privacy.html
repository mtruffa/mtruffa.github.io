Privacy policy

Jarvis · last updated 26 September 2026

Jarvis is a personal assistant that runs on its owner's own computer and is used only by its owner. This policy explains what it accesses, why, and where that information goes.

Google data it accesses

Only after the owner signs in with Google and grants permission, Jarvis uses:

  • Google Calendar events (calendar.events): to list the owner's events, add new events, and move existing events when the owner asks.
  • Gmail, read-only (gmail.readonly): to list, search and read the owner's messages when the owner asks about their email.
  • Gmail drafts (gmail.compose): to create email drafts for the owner to review. Jarvis contains no feature that sends email; the owner sends any draft themselves.

How it is used and shared

  • Calendar and email content is used only to answer the owner's own requests, at the moment they ask.
  • To understand a request, the relevant content is sent to Anthropic's API (the AI model that powers Jarvis), which processes it under Anthropic's commercial terms. Jarvis only uses Google data with Anthropic's models: its calendar and email features refuse to run on any other model.
  • When the owner asks Jarvis to phone them, a short spoken brief is sent to Retell AI to place the call. That brief can include the answer most recently shown on the owner's screen, which may mention a calendar event or email the owner had just asked about.
  • Google user data is never sold, never used for advertising, never used to train AI models, and never shared with anyone else.

Where it is stored

  • The Google sign-in token is stored in a file on the owner's computer that only the owner's user account can read. It is never sent to a web browser or any other service.
  • Jarvis does not keep copies of emails or calendar events. It fetches them when asked, and keeps a short text history of the current conversation in memory, which is cleared when Jarvis restarts.
  • Transcripts of phone calls Jarvis places are saved on the owner's computer.

Removing access

The owner can disconnect Google from Jarvis at any time, which revokes the token and deletes it, or remove Jarvis's access at myaccount.google.com/permissions.

Google API Services User Data Policy

Jarvis's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
